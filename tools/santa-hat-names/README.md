# Santa hat name shirts (Funny Accessories Etsy shop)

Per-order print file for the 3 "Custom Name Christmas ... Santa Hat" listings (adult tee, youth tee, baby bodysuit).

    python3 name_print.py "Sofia" sofia.png   # 4500x5400 transparent PNG, white Dancing Script 700 under the hat

Printify products hold a hat-only file. For each order: make the name file, then in the Printify order
replace the front design with it (same placement: adult/youth x0.5 y0.47 scale 0.9; baby scale 0.95) before it goes to production.
Check spelling against the Etsy personalization note.
